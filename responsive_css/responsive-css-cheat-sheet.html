Responsive CSS Cheat Sheet

Important concepts for responsive websites

Filters

Use filter to modify the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply CSS according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites work on different devices.

width: 100%;

Typography

Use relative units for flexible text sizes.

font-size: clamp(1rem, 2vw, 2rem);
